Send photos to the frame from your iPhone

Build this once in the Shortcuts app (about 5 minutes). Afterwards: select photos or videos in Photos → Share → Send to Frame. Keep this page open next to Shortcuts; the two values you need have Copy buttons.

Already have the Shortcut? Add the actions of step 6 you don't have yet just above your “Get Contents of URL”, and change its address as in step 7. Then videos keep their date and place (converting a video drops them), and captions show the place's name (new: Name, URL Encode, and &place=). Afterwards export it again for the frame (Settings → Add from your phone → iPhone Shortcut).

Ready-made Shortcut

Download it, open it, and tap Add Shortcut: it is already set up for this frame, so you can skip the steps below.

Download “Send to Frame”

Safari asks to download it; then open it from the Downloads list (the arrow in the address bar).

1Create the Shortcut

Open Shortcuts → tap + (top right). Tap the name at the top and call it Send to Frame.

Tap the ⓘ button at the bottom → turn on Show in Share Sheet → Done.

A block appears at the top. Tap its first blue word (“Any”, or “Apps and 2 more”) and leave only Images and Media selected. It should read:

⇪Receive Images and Media input from Share Sheet

2Add “Repeat with Each”

Tap the search field at the bottom, type repeat, and tap Repeat with Each. It should use Shortcut Input:

↻Repeat with each item in Shortcut Input
End Repeat

Steps 3 to 7 all go inside this block (between “Repeat” and “End Repeat”). If an action lands below End Repeat, drag it up.

3Photo or video? Get its media type

Search media type (the action is Get Details of Images) and add it inside the repeat. Set it to get Media Type from Repeat Item:

▣Get Media Type from Repeat Item

Then search if → tap If. It picks up Media Type by itself; set the condition to is → Image:

YIf Media Type is Image
Otherwise
End If

A new If comes with Otherwise and End If. If yours has no Otherwise, delete the If and add it again.

4Photos: “Convert Image”

Search convert image → add Convert Image right under “If” (above “Otherwise”). Set the format to JPEG.

Important: tap the blue input and choose Repeat Item. It often fills in Shortcut Input by itself, and then every pass sends the first photo again (only one photo reaches the frame).

Tap Show More (the arrow) → turn on Preserve Metadata (keeps the date and location).

▣Convert Repeat Item to JPEG Preserve Metadata: On

5Videos: “Encode Media”

Search encode → add Encode Media under “Otherwise” (above “End If”). Input: Repeat Item (same check as step 4).

Tap Show More → Size → 1920×1080 (not the HEVC one: it keeps HDR videos in HDR, which the frame can't play).

▶Encode Repeat Item Size: 1920×1080

Your block now reads: Get Media Type → If … is Image → Convert → Otherwise → Encode → End If.

6Date and place: four “Get Details” actions

Converting a video drops its date and location, so the Shortcut sends them along. Add these below “End If”, still inside the repeat.

Not inside Otherwise: there the video would be replaced by the longitude, and the frame answers “The Shortcut sent text instead of the photo or video”. If they landed there, drag each one below End If.

Search details of images → add Get Details of Images → set it to get Location from Repeat Item:

▣Get Location from Repeat Item

Search details of locations → add Get Details of Locations → Latitude from Location. Add it once more for Longitude:

⌖Get Latitude from Location
⌖Get Longitude from Location

Add Get Details of Locations a third time → Name from Location (the place's name, as in the Photos app, for example a church or a park). Then search URL encode → add URL Encode → Encode the Name:

⌖Get Name from Location
¶Encode Name

Photos keep their own date and place (step 4); sending them too does no harm. A video without a location just sends an empty one. Without a name the frame looks the place up on OpenStreetMap, or shows just the town.

7Send it: “Get Contents of URL”

Search get contents → tap Get Contents of URL. Place it below the actions of step 6 but above “End Repeat”.

Tap the blue URL field and paste this address (it ends with taken=):

…

Right after it, still in the URL field, add the date: tap Repeat Item in the bar above the keyboard (or Select Variable), tap the new blue Repeat Item → choose Date Taken → Date Format → ISO 8601.

Then type &lat= and add the Latitude variable, then type &lon= and add Longitude, then type &place= and add URL Encoded Text. The = goes before each variable (with the variable in front of it, the frame gets no place). The URL reads:

⇅http://…/api/upload?taken=Date Taken&lat=Latitude&lon=Longitude&place=URL Encoded Text

Tap the blue Date Taken once more and check it still says ISO 8601. Other date formats have spaces, and the address ends at the first space: the frame then gets no place and no name.

Tap Show More, then:

• Method → POST
• Headers → Add new header. Key:

X-Upload-Key

  Text (your frame's upload key):

…

• Request Body → File. Tap File → choose If Result (the converted photo or video from step 4 or 5, not Shortcut Input).

⇅Get contents of http://…/api/upload?taken=… Method: POST
Headers: X-Upload-Key = your key
Request Body: File · File: If Result

8Try it

Open Photos, select one photo → Share → scroll the list of actions → Send to Frame.

The first time, iPhone asks to allow connecting to devices on your local network, and Shortcuts may ask to allow sending to this address: tap Allow.

The photo appears on the frame within a few slides. Sending the same photo again is fine: the frame skips copies it already has.

Sending several photos at once? Turn on Settings → Shortcuts → Advanced → Allow Sharing Large Amounts of Data once. Without it, iPhone stops the Shortcut when many photos or a video are selected.

If something goes wrong, the Shortcut shows the frame's answer, for example “The upload key is wrong…”. Tell me what it says, or which step looked different, and I'll fix this guide.

The upload key only lets the Shortcut add photos and videos. You can replace it any time in Settings → Add from your phone → iPhone Shortcut → New key (then paste the new one in step 7). Settings
